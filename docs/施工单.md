# Rockey 施工单

> 状态：未开工。日期：2026-10-07。复选框全部为未来任务。
> [需求](./需求.md) · [协议草案](./Keymaster互操作协议草案.md) · [Keymaster 施工单](../../keymaster.cc/docs/proposals/rockey/Vault软硬件统一施工单.md)。
> 本轮只落需求与施工文档，不实现固件、不安装工具链、不刷机、不烧熔丝。

## 1. 施工顺序与归属

Rockey 负责板级支持、固件密钥保护、解析/密码学、设备策略、三按钮 UI、多语言字体、USB 设备侧和固件测试。Keymaster 负责统一 Vault、浏览器 USB 桥、数据库生命周期、业务构造和主机 UI。共同协议在本仓库唯一维护，双方固定版本及向量。

建议未来模块按 board、transport、protocol、key-store、crypto、operations、policy、ui、i18n/font、migration 和 tests 分开；目录命名在工具链选定后确定，不为目录骨架假称功能完成。任何实现并行工作先明确文件归属，不能回退他人变更。

## 2. R0：平台、协议与安全基线

- [ ] 确认 M5Stack 型号、PCB 修订、芯片、屏幕/旋转、按钮去抖、内存、USB 桥、电池与断线检测；记录真实硬件清单。
- [ ] 选定 ESP-IDF/Arduino 或其它适用构建工具、渲染库和维护中的密码学库，固定版本及可重复构建方式，不假定已有工具链。
- [ ] 与 Keymaster G0 冻结协议版本/schema/算法/限额/错误/握手/事件/向量；关键业务规范独立于 USB class。
- [ ] 冻结 PIN/KDF/保护封装、失败等待、计数原子性与磨损；在实际芯片测量，不把短 PIN 当物理攻击保障。
- [ ] 确认不保存旧软件封装建议、迁回后副本/擦除策略与设备外恢复格式。
- [ ] 定义开发/发布配置矩阵，无线关闭、日志脱敏、测试接口隔离和独立熔丝操作说明。

门禁：板型和协议无核心未定依赖，公开测试向量可被两端读取。可先做纸面/主机模型，不以模拟器验证真实芯片安全。

## 3. R1：板级 UI 与三按钮解锁原型

- [ ] 实现屏幕/按钮/电源最小驱动，输入事件去抖、短/长按和按住重复相互排斥。
- [ ] 实现逐位 PIN、删除/取消菜单、首次重复确认、失败清空、错误等待；暂用独立测试材料。
- [ ] 实现菜单与阅读动作：A/C 浏览、B 操作、长按返回；确认页进度与松键栅栏。
- [ ] 制作中文/日文/英文长文、完整公钥、长地址/金额、缺字和恶意换行样本。
- [ ] 测量解锁按键次数、阅读速度、返回位置、误触行为与可读性；调整 PIN/字号建议。

门禁：真实三按钮能独立完成解锁/阅读/拒绝/确认，不需要触屏、主机按键或组合手势；换页不会延续长按导致误确认。

## 4. R2：密钥封装、持久状态与锁定

- [ ] 单业务 Key 原子创建/导入/封装保存；有 Key 时不同 Key 拒绝覆盖。
- [ ] 用设备口令及保护材料解封；敏感缓冲生命周期、随机数、认证失败与锁定清理。
- [ ] 持久失败计数和参数版本；更改 PIN/升级封装/断电恢复不破坏旧记录。
- [ ] 所有日志/错误/调试通道无秘密，发布固件不含测试 Key 或 raw Key 接口。
- [ ] 评估芯片 Secure Boot/Flash Encryption/调试与下载限制；可逆开发先行，烧熔丝需独立已审阅操作。

门禁：存储/解锁/锁定与每个持久提交点故障注入；保护配置证据明确，未配置时不得宣传已保护。RAM 清理测试不替代物理抗攻击证明。

## 5. R3：USB、认证连接和会话模型

- [ ] 有界帧解析、分片、关联、版本/能力协商、认证配对与加密；错误输入不耗尽内存。
- [ ] 当前 Key 持有权证明、一个控制连接、多 App 会话与运行代际。
- [ ] 心跳/失活、锁定、会话关闭、取消和设备事件；电池供电断 USB 仍撤权。
- [ ] 排队上限与控制优先级，菜单可达；requestId 重放缓存/查询和未知结果处理。
- [ ] 联调 Keymaster Window/Worker 桥，多 Tab 只一个合法控制连接。

门禁：真 USB + 浏览器配对与断线，通过伪帧/超长/乱序/重放负向测试；传输 ACK 不误作签名成功。

## 6. R4：业务解析器与密码学兼容

- [ ] 导入身份 Key，DER/compact 显式签名、身份/意图规范对象；自算摘要并生成操作摘要。
- [ ] BSV P2PKH：前序证据、输入/输出、网络、找零、手续费及 sighash；支持集之外明确拒绝。
- [ ] Channel public/hash/private 编码、验签、seal/open；按协议类型建立可解释的操作范围。
- [ ] 现有 v3 本地秘密 HKDF/AAD/AES-GCM，设备内部派生，按 scope 提供 seal/open，不导出长期派生密钥。
- [ ] 文件摘要声明独立模板；摘要由主机计算的边界明确。
- [ ] 每个业务类型声明版本与能力，普通钱包无通用 hash 签名；复杂资产/专款协议逐类列入后续解析器。

门禁：TS↔固件黄金向量双向兼容、旧密文解封；错误对象/网络/脚本/承诺拒绝。估费/预览请求不触发真实签名。

## 7. R5：白名单决定与长文授权 UX

- [ ] 实现未决定/会话允许/会话否决及本次决定；设备本地取消持续决定，修订号推进、队列执行前复核。
- [ ] 绑定对象/协议/方向/App/会话及限额；Channel 不覆盖支付/导出，导出和擦除不可持续允许。
- [ ] 阅读页滚动、章节/进度、至少一行重叠、速度封顶、完整公钥与章节跳转。
- [ ] B 打开菜单，默认继续阅读；返回保留位置；允许进入固定摘要长按确认；拒绝随时可达。
- [ ] 重大警告和操作范围必经，详细全文可选；请求/说明冻结，变更重新审核。
- [ ] 可信度结构化证据与临时公钥加密接收，机构签名/请求绑定/时间状态；没有正式服务时用公开 fixture 验证，不伪造实际已查询。
- [ ] 主机文本与可信模板分区，UTF-8/控制字符/缺字/超限拒绝或明确标记，不隐藏关键风险。

门禁：持续否决重复请求无弹窗，取消后重新询问；撤权在事件丢失时仍阻止执行；长文中取消/锁定/插队/松键均不误签。

## 8. R6：多语言字体资源与构建参数

- [ ] 收集并固定 Noto Mono/CJK 与像素备选的源资源、精确版本/哈希、来源、版权/OFL 文件；资源放入仓库或受控本地依赖包，用户不手工找字体。
- [ ] 建立语言/地区文案 key，固定风险模板与恢复/错误页；缺翻译检查。
- [ ] LANG/FONT_PROFILE/GLYPH_SET 等预设，自动提取 UI 字形并添加数字/标点/所选动态字集。
- [ ] 确定性位图生成、重复字形去重、少数字号；容量超限与固定 UI 缺字使构建失败。
- [ ] 输出 Flash/RAM/字形/缺字报告；动态缺字可查码点；完整地址/公钥不受语言包影响。
- [ ] en/zh-Hans/zh-Hant/zh-HK/ja 分别编译真屏检查，换语言升级保留 Key 分区并撤销会话。

门禁：用户只用参数即可构建选定语言；离线资源可重复、许可证齐备，真实显示可读。没有下载/生成字体前不得标记本阶段完成。

## 9. R7：迁移、迁回与设备外恢复

- [ ] 设备菜单主动进入导入，完成配对后接收 Key，原子保存并提供公开进度/兼容验证。
- [ ] 同迁移重试查询、不同迁移冲突、主机提交前/后恢复；不与正常签名并行。
- [ ] 主动迁回重新 PIN、固定警告与长按确认，一次性认证加密导出，普通会话/App 不可调用。
- [ ] 设备副本删除规则先冻结，主机新封装可恢复提交前不擦除设备唯一副本。
- [ ] 设备外恢复备份及校验准确单 Key；验证新设备恢复后原 Keymaster 数据仍可用。
- [ ] 设备擦除独立物理确认，不因浏览器注销自动执行。

门禁：双向迁移每个提交点断电恢复，身份与旧数据兼容；导出与备份不误称硬件从未泄露 Key。

## 10. R8：发布与联合验收

- [ ] 创建公开测试 Key 的主机模型/固件测试/真机验收，报告分层记录 RK-01 至 09。
- [ ] 联合 Keymaster KM-RK 场景，验明真浏览器/USB/屏幕/按钮与多页面失活。
- [ ] 发布构建扫描无测试按键、绕过授权、任意摘要或私钥调试入口，日志/报告扫描秘密。
- [ ] 记录固件构建 ID、配置、板型、字体清单/哈希、安全功能实际状态及未支持能力。
- [ ] 形成可重复构建/升级/恢复说明；用户自编译与签名固件升级策略明确，不承诺任意自编译镜像自动被 Secure Boot 接受。

建议后续验收矩阵作为机器可读唯一状态源，报告链接指向实际构建/样本。当前只定义验收要求，不创建虚假的完成证据。

## 11. 后续扩展

FIDO/CTAP2、独立实验密钥和通用密码学 Lab、复杂 BSV 资产解析、更多信誉服务、可信时间/更强硬件保护。每项独立规格与能力版本，不通过 Lab 入口给正式 Key 增加盲签；板型不支持的原生 USB 功能不得只靠软件声明。

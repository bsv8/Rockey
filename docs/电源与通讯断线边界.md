# 电源与通讯断线边界

2026-10-11 用户最终决定：不再管理电池板、电源切换、拔线关机或电池状态，用户自行处理物理断开与关机。此决定替代此前 USB 拔线锁定/关机、电池 GPIO 检测和关机菜单需求，不新增自动重连业务。

## 设备行为

- 通电且未复位：空闲、USB 拔线、浏览器关闭、通讯心跳超时均不自动锁定私钥。设备不显示电池信息，不轮询电源芯片，不识别物理 USB 状态，不控制电池或关机。
- 通讯失效：原 USB 加密会话结束，待处理请求和该会话授权撤销；设备仍保持本地 PIN 解锁状态。重新连接必须重新握手、配对及验证同一公钥的持有权，不恢复旧会话许可。
- 用户关机：实际断电/重新启动后从锁定状态进入 PIN 流程，等同钱包锁定；硬件是否平滑切换电源、是否自行重启不由钱包固件修复。
- 显式“立即锁定”、改 PIN、密钥迁移等既有清理流程仍保留；菜单不提供关机按钮。

## Keymaster 连接

现有串口桥在断线时关闭端口和租约，`HardwareConnectionOwner` 撤销后端，Coordinator 将浏览器钱包置为锁定。这里的浏览器锁定表示没有可用硬件连接，不表示强制擦除仍通电设备的本地私钥。

插回后用户点击“连接 RocKey”，选择端口、重新核对配对码。Worker 用同一持久硬件 Key 记录核验公钥与持有权，重新激活原钱包，身份和数据继续使用。现有代码没有自动续接旧连接；如果设备及打开端口过程均没有导致复位，本地无需再输入 PIN。若硬件发生重启，则先按设备正常 PIN 流程解锁。

不自动重放断线时未完成的支付；既有付款状态查询和防重放机制继续生效。持久渠道配置、消费记录与钱包数据不因连接重建删除。

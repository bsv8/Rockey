# 中文绘制回归

使用带 Pillow 的 Python 运行 `check.py`。构建入口的主机门禁自动调用此检查，Python 可通过 `ROCKEY_PYTHON` 指定。

检查编译真实 `display.cpp`、`font.cpp`、`text.cpp` 和当前生成字库，只将 TFT 的像素输出接入软件 framebuffer。22 组中文标题/正文、ASCII/数字/下划线及裁剪结果，逐像素和逐宽度与固定源字体的 Pillow/FreeType 输出比较。旧 UTF-8 首字节绘制实现作为负对照无法通过。

同时调用产品实际使用的 `device-ui/presentation.hpp` PIN 绘制函数，验证 0–9 在六个输入位置上的 60 组逐像素结果，含当前位框和已输入数字。设置、重复确认与解锁共用此函数。可设置 `ROCKEY_BOOT_PREVIEW=/绝对路径/boot.png` 导出真实启动绘制算法的软件像素预览（不代表实体 LCD 截图）。

这里验证真实绘制算法，不验证实体 LCD、背光、电气连接或屏幕观感。字体生成需先选择默认的 `zh-Hans / fusion-pixel / common`；实际多语言固件仍由构建入口分别生成。

2026-10-11 修复：屏幕绘制/测宽使用真正的 UTF-8 码点；生成字形的偏移与长度使用位而非字节；字形顶的位置相对基线计算，允许负偏移表示下划线等基线下字形；正文/等宽字集补齐 A–Z，避免地址、PIN 提示和动态文字缺字。钱包和授权行为不变。
